# EVENT.KITA – Student Event Management Platform

**Discover. Join. Experience.**

## About the Project

EVENT.KITA is a student event management platform designed to help university students discover, explore, and participate in campus events.

This repository contains the initial UI/UX design exploration and screen prototypes generated using **Google Stitch** and developed with assistance from **Google AI Studio**.

This repository is currently used as a temporary workspace for storing design references, HTML screen exports, and project assets before the main development process.

## Project Features

The planned features of EVENT.KITA include:

- Event discovery and search.
- Event details and registration.
- Interactive event calendar.
- Student event registration history.
- Panitia event management dashboard.
- Participant management.
- Event documentation gallery.
- Activity reports.
- Admin dashboard and event verification.
- Role-based access control.

## User Roles

EVENT.KITA has three main user roles:

| Role | Description |
|---|---|
| Admin | Manages users, event verification, categories, and activity reports. |
| Panitia | Creates and manages events, participants, documentation, and reports. |
| Mahasiswa | Explores events, registers for events, views schedules, and accesses documentation. |
